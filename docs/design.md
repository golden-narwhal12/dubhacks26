# Design

mudroom uses near-black green-neutral surfaces, phosphor green accents and warm off-white text, with muted amber/cyan/coral/lilac supporting colors. Centralized CSS tokens define the palette; errors stay coral/red and warnings amber rather than using green indiscriminately. Content occupies the window; no branding banner, slogan, persistent bottom strip or decorative metrics. Native macOS title bar shows the project name. Application menus own file/edit/settings/layout operations. One 40-pixel toolbar holds Verify, Program Board, a compact project-board/physical-port selector, secondary Simulate, issues and Prototype/Debug. Dock tabs are 28 pixels; panes retain drag/tab/resize/float/maximize/reset.

Prototype defaults to Circuit / Code / Agent. Debug defaults to Device / Circuit / Agent, with Code tabbed beside Circuit. Layouts persist independently; shared project/history/conversation stay intact. Switching is a navigation action with no physical or inference side effect. Successful approved programming enters Debug; upload failure stays in context.

Settings and action reviews use native HTML dialog top layer. This covers floating groups/sashes, makes underlying content inert, contains keyboard focus, supports Escape, and restores focus. Do not replace this with a low-z-index backdrop. The action card is specific: target/device, operation, immutable artifact/config/source, verification/issues, restart/control-line side effects, active Approve/Cancel. Preparation/running operations have Stop; cancellation is best-effort rather than undo of hardware.

Agent's unconfigured state contains its interchangeable mark, “No API key connected.” and “Connect a provider.” Provider/model, composer and participation controls remain compact. Tool messages expand on demand. Suggestions and telemetry refreshes never infer by themselves.

Circuit artwork is original illustrative vector geometry. LED has narrower proportions with matching pins/bounds. Terminal selection opens only populated short facts; Evidence and advanced bindings are collapsed actions. Generic passive properties are inline, validated and undoable. Exact old packages retain fixed values and sources. Picker categories replace verbose capability badges; a small green check means the package's declared pin-map scope was cross-checked, not universal circuit verification. Generic/provisional parts never receive that check. Search has an underline and subtle visible focus, without an enclosing pill.

Routing is view-only deterministic orthogonal visibility-grid search with component obstacles, terminal lead-outs and reserved segments. Unrelated nets cannot share a visible collinear segment. Canvas-colored crossing halos distinguish crossings without junction dots; selection/hover rings identify actual endpoints. Interior breadboard leads necessarily exit their addressed hole across their own breadboard surface; other bodies remain obstacles. Blocked routes show a short explicit warning rather than a hidden path. Move/rotate to adjust; manual bend editing is deferred. Initial route-aware fit is immediate; explicit Fit View includes routes and can animate. Dense Mega inner/outer header rows are visually staggered to separate lead-outs; artwork is not a dimensional manufacturing drawing.

Component/connection errors use larger red circled-exclamation indicators and concise activation details. Warnings retain amber; unknown checks remain neutral. Issues and Output are accessible through toolbar and View menu. Known firmware locations have Monaco squiggles, never invented arbitrary-code locations. Technical logs remain collapsible/on demand.

Debug uses raw serial output plus explicitly mapped readouts, bounded history plots and summaries. Host receipt time, device timestamp and declared units remain distinct. Missing is “Not reported”; stale and invalid data do not become zero. “Commanded position” does not imply servo feedback. Readout labels never infer measured voltage or mechanism calibration. Serial command review displays exact escaped bytes/line endings; reset identifies its control-line mechanism.

React Flow's installed MIT license and [official ProOptions guidance](https://reactflow.dev/api-reference/types/pro-options) permit hiding the visible attribution; copyright/license notices are retained in the native package's licenses directory. No Pro subscription or exemption is claimed.

Agent activity is one quiet collapsed group per task, with locally derived step counts and stable request/call identity. Expansion exposes names, state, bounded arguments/results and timings; failures stay visible even collapsed. Actual assistant messages, applied changes, review diffs and trusted hardware cards stay separate. Approved local batches continue automatically. Genuine questions use a compact choice card with free text and an explicit Send answer; nothing is preapproved. Only stopped budget/error recovery exposes Continue task. No model call summarizes activity.

Each Issues row and circuit issue popover has an accessible Ask Agent action with Explain/Fix choices. Explain is read-only; Fix is a bounded authorized local repair followed by checks. Opening, hovering or dismissing never invokes a model. Missing credentials lead to Settings with the selected issue retained and an explicit Continue action after configuration. Stale issues are resolved against current state at activation. Outside pointer interaction dismisses circuit issue popovers without consuming selection/drag/pan/wire gestures; inside actions remain usable. Escape restores the trigger focus, another issue can replace it, and native modal precedence remains intact. Task-limit controls are compact and disclosed in Settings; reported-token threshold is labeled separately from response output/request/tool/time limits.

The reported-token threshold defaults to 1,000,000 and remains distinct from model output/context limits. Settings controls use a compact two-column layout. Established LED limiting and binding/mapping fixes can be previewed without AI. Ask Agent may apply those same validated fixes. Unresolved physical conditions and remaining local issues are labeled separately from compilation success; local checks never trigger a new inference task.

Native Edit → Undo/Redo follows the focused text control when appropriate. Project → Undo Project Change / Redo Project Change explicitly uses shared project history regardless of text focus. Property blur commits compare current state so focus changes cannot insert duplicate no-op history entries.

New agent-created components receive deterministic spacing when requested placements overlap existing artwork, with rotated bounds and lead-out clearance. The adjustment stays in the same undo/review group; existing components are never rearranged automatically. This prevents small components from disappearing over the much larger Mega illustration. It does not promise an optimal layout for every circuit.

Circuit issue popups use anchored native nonmodal top-layer popovers outside the SVG/node stacking context, so wires and floating groups cannot cover them. Outside clicks retain selection/drag/pan intent; Escape restores the trigger; modal dialogs take precedence. Routing reserves name labels and issue hit targets, with header lead-outs turning before them. Larger generic ICs use two-sided terminals and dynamic bounds; supply and level-shifter visuals identify power references clearly. Unknown source voltage is not drawn as 5 V.

The Issues toolbar shows total errors plus warnings, red when any error exists, amber for warnings only and green when neither exists. Unknown coverage remains separate. New chat is explicit in the Agent toolbar. New Project clears the old conversation, output and history rather than carrying them into the blank canvas.

## Terminal theme / naming

User direction, 18 October: the product name is **mudroom**, always lowercase. Keep the workspace geometry and quiet interface; the theme should suggest terminal tools without theatrical scanlines, glow, animations, gamer slogans or a replacement branding header. Canvas is `#0c0f0d`, panels `#111512`, raised surfaces `#1a201b`, accent `#9af56a`. Distinct wire colors and semantic diagnostic colors remain readable.

User feedback restored the original system sans-serif interface font and SFMono/Menlo code typography. Logs and ASCII glyphs use the original system monospace stack; no custom font loads. ASCII `>_` for Agent, `[+]` for a new chat, `[?]` for contextual AI, and `{}` for firmware tabs are decorative glyphs with conventional accessible control names. Standard controls and safety icons remain familiar. Border radii are subtly tighter; an active dock tab has a fine green line. New app artwork is an original lowercase m/cursor vector, not a raster asset.

Renaming preserves legacy `.trace.json`, storage/IPC identifiers, bundle ID and existing keychain/profile identity. New example source uses the new name; previously saved user firmware is never rewritten for branding.

Repository overview uses an actual offline Electron capture in `docs/images/workspace.png`; it shows the default indicator example and unconfigured Agent rather than invented conversation or physical-device readings.
