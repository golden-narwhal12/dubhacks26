# Additional catalog packages

`src/parts/additional.ts` adds 24 version-1 packages. Existing immutable packages retain their IDs/versions. These definitions support documented design and explicit wiring; **none adds peripheral, analog or mechanical simulation**. Generic templates describe logical roles, not a claimed exact physical inventory. Their assumptions are provisional and they do not receive verified-pin badges.

| Packages                               | Scope                                                                                                                                                 |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| External DC supply                     | Positive/negative terminals. Intended voltage/current capacity are instance declarations, not measured output or proof of available hardware.         |
| Capacitor; polarized capacitor; diode  | Separate terminals and explicit polarity where appropriate. Voltage/current/power/ESR/chemistry remain unknown until specified from an actual device. |
| NPN; N-channel MOSFET                  | Logical B/C/E or G/D/S; no invented physical pin order, gain, current rating or gate-drive compatibility.                                             |
| Pushbutton; SPDT switch; SPDT relay    | Logical contacts, with relay coil separate. Dynamic contact state is unsupported; contacts are not permanent net shorts.                              |
| Two-/four-contact connectors           | Isolated logical contacts; no assumed JST/Grove/Qwiic pinout or mating relationship.                                                                  |
| Photoresistor; NTC thermistor          | Bare resistive sensors requiring bias and calibration; ADC counts do not become lux/degrees automatically.                                            |
| Passive piezo buzzer; brushed DC motor | Actual load ratings/drivers unknown. No automatic sound, speed measurement or GPIO-power assumption.                                                  |

For the servo/encoder assembly, the external-source package lets the diagram retain a complete servo power path and common ground instead of removing the power connection. The Adafruit package lets an agent document a real two-channel 5 V/3.3 V I²C translation path, using the remaining channels only if needed. Neither package confirms the user's physical equipment: actual supply regulation/capacity, the photo-matched AS5600 module's circuitry, magnet coupling/alignment and calibration still require confirmation. Board and sensor supply domains remain distinct from signal levels.

Verification: `npx vitest run tests/catalog-additional.test.ts` checks stable identities/evidence references, provisional generic status, exact package pin maps and the absence of false internal shorts. This is definition verification, not physical-device testing. The original manufacturer drawings remain the authority for package orientation.

Selected exact IC supply operating ranges are checked only where recorded primary evidence supports them; recommended conditions remain distinct from absolute maxima. AS5600 register/address/magnet-status facts are cached separately in `src/parts/referenceFacts.ts`, with their own evidence revision; those chip facts do not establish the anonymous breakout’s regulator or pull-up circuitry.
